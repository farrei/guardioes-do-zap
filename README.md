# Guardiões do Zap

Jogo educativo para ajudar usuários iniciantes a reconhecer golpes em mensagens, especialmente em situações parecidas com golpes comuns no WhatsApp.

## Objetivo

O projeto foi criado como material complementar para uma atividade extensionista sobre prevenção de golpes digitais.

A proposta é ensinar, de forma simples e interativa:

- Não clicar em links suspeitos
- Não compartilhar códigos de confirmação
- Não informar PIN ou senha
- Confirmar pedidos de dinheiro por outro meio
- Bloquear e denunciar contatos suspeitos
- Ativar verificação em duas etapas

## Como funciona

O usuário joga missões com conversas simuladas.  
Em cada missão, aparece uma mensagem suspeita e o jogador precisa escolher a atitude mais segura.

O jogo possui:

- Pontuação
- Vidas
- Recorde salvo no navegador
- Cartas educativas
- Checklist visual de risco
- Modo letras grandes
- Certificado simbólico ao concluir
- PWA básico

## Como publicar no GitHub Pages

1. Crie um repositório chamado `guardioes-do-zap`
2. Envie todos os arquivos deste projeto
3. Vá em `Settings > Pages`
4. Em `Source`, escolha `Deploy from a branch`
5. Em `Branch`, escolha `main` e `/root`
6. Clique em `Save`

O link final ficará parecido com:

```txt
https://farrei.github.io/guardioes-do-zap/
```
